# THEI Agent Onboarding Process

Source: THEI Notion pages **Agent Onboarding & Contracting** (2026-07-13) and **Agent Onboarding Process Guide** playbook (2026-05-30).
Conflict rule: prefer these Notion pages over generic Hub `hub/getting-started`. Hub still has AgentSync / Nextere portal how-tos.
This file is process only — no agent names, SSNs, DOBs, NPNs, license numbers, or personal contact info.

Nextere vs AgentSync: **Nextere is only for Doctors, HealthSun, and Solis** (tenant **NHP**). Other carriers go through AgentSync / AgentX / the carrier portal. See `onboarding/nextere-steps` and `onboarding/carrier-contracting`.

FMOs: **New Health Partners (NHP)** and **YourPlanChoice, LLC** are both active, for different carriers. Carriers are tagged by FMO in `onboarding/carrier-contracting`.

## Onboarding checklist

- Contract signed and filed
- License verified (E&O / active license on file)
- Background check completed
- Carrier appointments submitted
- System access granted (email, CRM, phone system)
- Training completed
- Added to Team & Agents roster

## Agreements

- **GA** (recruits downline) → DocuSign template `GA_Agreement_2026`
- **Individual agent** → DocuSign template `Agent_Agreement_2026`

Save the signed copy to the agent’s Google Drive folder along with their AHIP certificate.

Once DocuSign is signed, trigger **Nextere** and **AgentSync** invites from the signed agreement (legal name, DOB, address, NPN, license #). The agent completes AHIP and carrier appointments on their own. After the first Ready-To-Sell (RTS), add them to MedicarePro (CRM) and the GHL lead routing workflow.

Portal: https://www.agentmedicarehub.com/start (bilingual EN/ES).

## Playbook (DocuSign → platforms → AHIP → RTS → Active)

### STEP 1 — New agent recruited (about 2 minutes)

1. Open the Agent Onboarding Tracker in Notion and add a row.
2. Fill type (GA or Individual), language preference, date added, status **New Lead**, next action: send portal link + DocuSign.
3. Save.

### STEP 2 — Send portal link + DocuSign (about 5 minutes)

Send the correct DocuSign template (GA vs Individual) and a short welcome. Match language to their preference; the portal itself toggles EN/ES.

Update tracker: status **Portal + DocuSign Sent**; set welcome / DocuSign sent dates; next action: wait for signed DocuSign.

### STEP 3 — Wait for signed DocuSign

No active work. DocuSign emails when it is signed.

- **3 days with no signature:** friendly follow-up. Point them at `agentmedicarehub.com/start`. Log the follow-up.
- **7 days with no signature:** status **Stalled**. Decide whether to escalate, archive, or try one more outreach.

### STEP 4 — DocuSign signed → trigger platforms (about 10 minutes)

1. Download the signed DocuSign into the agent’s Drive folder.
2. Use the signed agreement to invite them in **Nextere** and **AgentSync**.
3. Tracker: status **DocuSign Signed → Platforms Triggered**; record invite dates; next action: wait for AHIP + carrier RTS emails.

### STEP 5 — Monitor progress (about 5 min/week)

The agent is responsible for AHIP, accepting both invites, carrier appointments, and training. Check in weekly only if **Stalled**.

If **14 days with no progress:** send a check-in pointing at `agentmedicarehub.com/start` and log it.

### STEP 6 — AHIP completed (about 2 minutes)

Save the AHIP certificate to their Drive folder. Record AHIP completed date and certificate number in the tracker.

### STEP 7 — Carrier RTS emails

RTS emails go to the agent (they forward, or verify in carrier portals). For each RTS, add the carrier to **RTS Carriers**. Status **Partial RTS** until all expected carriers are in, then **Fully RTS**.

### STEP 8 — Agent goes active (about 10 minutes)

After the **first** carrier RTS they can sell that carrier. Then:

1. Add to MedicarePro so they can receive leads.
2. Add to the GHL lead routing workflow.
3. Send a ready-to-sell note (remaining appointments/training still need wrapping up).
4. Tracker: status **Active Agent**; set active date; next action none.

### STEP 9 — 30-day check-in (about 5 minutes)

Thirty days after Active: personal check-in. Record the date and any feedback.
